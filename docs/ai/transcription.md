# Transcription backends (stage 5), in the order they are tried

1. **Groq Whisper** (free tier, `GROQ_API_KEY`): first. A file that is not of a type Groq accepts (flac, mp3, mp4, mpeg, mpga, m4a, ogg, opus, wav, webm), such as the unnamed download of a TikTok video, or a big video, is first turned into a small mono MP3 (a mono WAV if the runner's ffmpeg has no MP3 encoder) with ffmpeg.
2. **Cloudflare Workers AI Whisper** (`@cf/openai/whisper-large-v3-turbo`; the free Cloudflare account the pool already uses: `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN`): second, up to 10 MB of audio.
3. **Faster-Whisper** (free, CPU, on the runner): the local backup, installed with a pinned compatible pair, `faster-whisper==1.1.1` and `av==13.1.0` (the unpinned install failed with "unexpected keyword argument metadata_errors").
4. **VibeVoice-ASR** (Microsoft): last. **Licence settled on 2026-11-19: MIT** (the VibeVoice-ASR weights and the CPU-only VibeVoice-ASR-BitNet variant are published under MIT on Hugging Face; the original VibeVoice-ASR needs a GPU with about 24 GB, so only the BitNet CPU build, `microsoft/VibeASR.cpp`, can run on a free runner). It is wired as a command: set the repository variable `VIBEASR_COMMAND` to the command of that build, with `{audio}` for the file, and it joins the chain; with no command it is skipped with a printed note. The install steps of that build could not be verified from here.

Not wired: OpenRouter's audio endpoint (nothing here shows it carries a free Whisper route). The measured order is written by Actions > Stage tools > `probe-transcribe`; a backend that fails is left last, never dropped. When one backend stops working the next is used; the run fails only when every backend has failed, and then it says why for each.
