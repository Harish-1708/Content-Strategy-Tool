# OmniRoute's free providers: the research, recorded (2026-11-17)

The planner's research is kept machine-readable in `ai/omniroute_free_providers.yaml` (a record: nothing reads it at run time, and `ai_providers.yaml` is still what the tool routes by). This page says what it means.

**Direction:** include all available free providers at once and test them together in the pool retest. This extends the routed client that already exists (the free pool first, Claude as the fallback and coordinator): the refresh and the foundation chain already call it. It adds no second path.

**Where the new providers stand:** NaraRouter, xKiro, SambaNova, llm7, SiliconFlow and Pollinations are already LISTED in `ai_providers.yaml`, switched OFF, with their terms unverified and no model approved. Turning one on takes three things only the owner can supply: its key as a GitHub secret, its terms read and recorded, and its first approved model id (learned from the pool retest, because the remote catalogue stays off). The tool does not flip them, and the loader would refuse an unverified provider anyway. OpenCode Zen is not listed at all.

**OmniRoute is wired (2026-11-17).** `contentintel/ai/omniroute.py` starts the pinned OmniRoute (3.8.53, installed from npm by `.github/actions/ai-pool`) on localhost for one job, logs in with a password made up for that run, creates one client key and registers each enabled provider's key with it. The router calls it like any OpenAI-style endpoint; the order of providers, the failover and the fallback to Claude stay the tool's own ranked lanes. It was proven on a real local OmniRoute with a stand-in upstream (it boots in seconds, hands out a key, routes a chat, and the upstream receives its own key, not ours). **Not proven:** real providers through it (no provider keys in the proof environment). To route a provider through OmniRoute, add `omniroute: {provider: <OmniRoute's id for it>}` to its entry in `ai_providers.yaml` and give its models the `provider/model` ids OmniRoute routes by; then enable it with its key as a GitHub secret.

**Rules that stay:** a provider is switched on only by the owner, with a key, after reading its terms; the five providers whose terms forbid proxying (Kiro, DuckDuckGo AI Chat, Blackbox, Coze, Muse Spark web) are never wired; pin a free model id per provider (a rotating roster must not swap models silently); no personal or confidential data on a provider that logs or trains on prompts (Kilo's Auto Free); when a provider stops working the tool moves to the next working one, and when none can do the job the run says so plainly.

**Video:** nothing in the pool is a reliable free video route (see the `video:` block of the data file). Pollinations stays a text-and-image lane to test last.


## The second research pass (2026-11-17)

A second pass over OmniRoute's full catalogue found 13 more free providers, 21 to reject, 5 still unconfirmed and 6 corrections to the first report (all recorded in `ai/omniroute_free_providers.yaml`, block `second_pass`). This tool checked each finding once against OmniRoute's own catalogue and, for the three it wired (Api.Airforce, BluesMinds, BazaarLink), against one outside page; "confirmed" in the research means the provider's published page, not a call. Wired through OmniRoute and switched on (each needs its key as a GitHub secret): **airforce**, **bluesminds**, **bazaarlink**. Not wired yet: the keyless ones (OVH AI Endpoints, AI Horde, UncloseAI), because the tool's OmniRoute start needs a credential and keyless handling must be proven live first; Morph (code editing only); Baidu ERNIE (real-name verification); Nous Portal and GitLawb/Twigpine (not in OmniRoute's free-models list, so no id to map); the search APIs (Exa and Tavily are already search providers). SenseNova is not free; the 21 rejected and 5 unconfirmed are never wired (NLP Cloud is never to be wired through a proxy).

The provider test (Actions > Provider test) is where every one of these is confirmed live. Which providers end up first for each job is decided by the pool retest, never by this list.
